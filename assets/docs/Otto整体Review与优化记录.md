# Otto 编舞台整体 Review 与优化记录

## 结论与范围

本轮完成单文件编舞台的可靠性、数据保真、时序编辑和响应式优化；**没有把模型侧面相似度当作代码回归结论，也没有完成真机同步验收**。

工作文件：`D:\jarvis\otto-choreographer.html`。浏览器双击本文件离线打开，已有页面需刷新；不需要服务器或额外资源目录。

回退存档：`D:\jarvis\_backup\otto-choreographer-整体优化前.html`。存档与改前文件 SHA256 一致。

仅改 HTML。固件只读，无 WebSocket 真机连接、无下发、无烧录、无物理微调。项目目录其他文件不删除、不移动、不重构成多文件工程。

## 已复现并修复

| 问题 | 原因与影响 | 修复结果 |
|---|---|---|
| 局部 JSON 被改写 | 导入时给每帧补 Home，后续未指定关节意外归位 | 保留稀疏 s；仅预览解析继承前帧。修改单轴仅写该轴 |
| 总延迟丢失 | buildSequence 固定 d=0 | 保留并可编辑顶层 d，播放也执行该延迟 |
| 非法数据与 HTML 注入 | 字符串舵机值可进入 innerHTML | 先验证全对象，再原子提交；拒绝非法键、对象形状、非数值、越界、无效振幅和混合帧，不损坏当前序列 |
| 振荡编辑丢脚与相位 | 表单仅覆盖4轴，编辑新建为一套默认值 | 六轴均可编辑振幅、中心、相位；原有脚轴/显式零值/相位保留 |
| 播放与下发语义不同 | pose 总用Home补全，osc 结束回到旧姿态 | pose继承；osc缺省中心90，结束以中心角作为基准；普通移动使用线性时间插值 |
| 停止后立即重播竞争 | 旧 Promise/长延迟仍可写共享状态 | 每次播放独立令牌，取消 rAF/延迟并解除等待；旧运行不能覆盖新运行 |
| 播放中改滑块丢输入 | 停止同步滑块后覆盖用户刚输入的角度 | 先捕获输入再停止，保存新输入；后台停止预览 |
| 帧操作选中错误 | 交换、删除只处理部分索引 | 正确保持选中帧身份，支持键盘选帧 |
| 耗时必须改 JSON | UI 未提供姿态帧 v/d编辑 | 选中姿态帧可直接修改耗时和帧后延迟，非法输入回退 |
| 连接竞争与误报 | 旧socket关闭覆盖新连接；仅识别顶层 error；发送即宣称下发完成 | IP/主机名校验、可取消连接、8秒超时、旧事件隔离、嵌套错误解析；文案区分已发送/设备确认/动作完成 |
| 下发缺安全检查 | 导入可绕过腿振荡锁脚限制 | 未锁脚、双腿/双脚大幅固件限幅、超出0–180的振荡可预览提示，但禁止下发，不静默修改预设 |
| 窄屏预览挤没 | 固定三列且body禁止滚动 | 中窄屏堆叠，预览优先；姿态库完整、控件可滚动可操作，无水平溢出 |
| 弹窗遮挡末端输入 | sticky 按钮盖住输入 | 去掉遮挡；滚动到底可看到延迟和保存按钮，支持Escape/Tab循环 |
| 重复几何解码与重绘 | 同类原网格多次base64解码、移动事件同步渲染 | 解码缓存后克隆，保留原数据；高频视角请求合并一帧；包围盒仅姿态改变后更新；渲染尺寸/相机宽高比匹配canvas，窄屏像素比上限1.5 |

## 保留与验证方式

- 原 5 类网格的全部顶点、三角形、尺寸及嵌入数据保持一致；不简化、不拉伸，不改变当前装配候选。
- 内嵌渲染库逐字一致；没有外部脚本或运行时 fetch 依赖。
- 16 个 PRESETS 定义逐字一致；Home 45/135、handLift 分段映射保留。脚和髋的原3D轴映射本轮未反转。
- JSON-RPC仍使用 `self.otto.servo_sequences`，`arguments.sequence`仍是字符串化 JSON；连接地址保持 `ws://设备IP:8080/ws`。
- JSON验证范围按已读固件实现：角度0–180整数，振幅0停用/10–90整数，周期100–3000整数，周期数0.1–20，phase0–360数值。延迟允许0–600000整数；最多1000帧。未知字段拒绝且报错，不忽略。
- 默认振荡p/c按当前固件解析器实际值300/8；显式输入保留。原固件描述示例与实际默认存在差异，以实现为准。
- 正常照片纹理后备保留；WebGL丢失停止本地播放，恢复时重绘，不自动刷新导致序列丢失。

## 未完成与已知缺口

- **商家白蓝款侧面和爪型仍未完成1:1验收**。原作者网格与商家照片版本有差别；本轮只是保存候选并补齐左右侧视入口，不能把数学轴或无裁切等同装配正确。
- 无物理碰撞/受力求解；落地仅把最低脚放到舞台，不是动力学。
- 未连接真实设备；模拟socket通过不代表设备支持工具、成功排队或动作执行完毕；停止预览不停止设备。
- 尚无撤销/自动保存。刷新前请复制序列JSON保留编舞；本轮未引入持久存储或云端。
- 预设“欢呼”等存在中心+振幅超界，会被新检查提示并阻止下发；未擅自改写预设角度，用户需要调整到合法范围后再发送。
- 初始编舞基准使用Home；设备当前实际姿态无法从此离线页面获知，启动预览不等于真机已归位。
